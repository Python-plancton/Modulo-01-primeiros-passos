## Como estudar este módulo

Siga a ordem abaixo. Não pule etapas.

**1. Leia o arquivo de teoria**
Cada tópico tem um `.md` com explicação, exemplos e tabelas de referência.
Leia com calma antes de abrir qualquer exercício.

**2. Abra o notebook de exercícios**
Os arquivos `.ipynb` têm os exercícios organizados em três níveis:
- **Nível 1** - conceito puro, sem pegadinha
- **Nível 2** - combinação de conceitos
- **Nível 3** - desafio no estilo LeetCode com função e casos de teste

**3. Tente resolver sozinha**
Se travar, releia o `.md` do tópico antes de consultar o gabarito.

**4. Consulte o gabarito**
O arquivo `gabarito.py` tem todas as soluções.
Use para comparar abordagens — não para copiar.

## Como rodar os notebooks

### Opção A - VS Code (recomendado)
1. Instale a extensão **Jupyter** no VS Code
2. Abra o arquivo `.ipynb`
3. Clique em **Run All** ou rode célula por célula com `Shift + Enter`

### Opção B - Jupyter no terminal
```bash
pip install jupyter
jupyter notebook
```
Acesse `http://localhost:8888` no navegador e abra o arquivo.

### Opção C - Google Colab (sem instalação)
1. Acesse [colab.research.google.com](https://colab.research.google.com)
2. Clique em **File → Upload notebook**
3. Faça upload do arquivo `.ipynb`
